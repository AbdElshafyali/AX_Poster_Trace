# AX_Poster_Trace Studio

مستودع وتطبيق تقسيم البوسترات واستخراج خطوط الشف والتحديد للطباعة على عدة صفحات A4 مع ميزة تخفيف الحبر للتحديد اليدوي بالجاف.

## المميزات الرئيسية
- **تقسيم البوسترات متعددة الصفحات (Multi-Page A4 Tiling):** تقسيم أي صورة أو مستند PDF على شبكة مخصصة من صفحات A4 (مثل 1×1، 2×2، 3×3، 4×4 أو حتى 10×10).
- **هوامش الأمان والتداخل (Overlap & Margin Guides):** طباعة هوامش ركوب وتداخل لتسهيل لصق وتركيب الورق بدقة متناهية مع خطوط قص منقطة وعلامات زوايا.
- **تخفيف الحبر الفائق للشف (Faint Ink Stencil):** التحكم في نسبة الحبر (من 1% إلى 100%) لطباعة خطوط رمادية شديدة الخفة تناسب الشف بالقلم الجاف والتلوين.
- **استخراج خطوط الرسم والتحديد (Sobel Edge Tracing):** تحويل الصور والرسومات المعقدة إلى خطوط خارجية صافية (Contour Outline).
- **تنظيف وتبييض الخلفية 100%:** إزالة أي اصفرار أو ظلال في الورق الأصلي لتوفير الحبر وضمان خلفية بيضاء نقية.
- **لوحة تحكم جانبية متجاوبة (Desktop & Mobile):** قائمة إعدادات جانبية مع شاشة معاينة حية بالكامل وتوافق مع أجهزة الكمبيوتر والموبايل (وضع الشاشة المنقسمة).
- **تحديد وطباعة الصور المجمعة (Batch Printing):** إمكانية رفع عدة صور وتحديد المراد طباعته منها دفعة واحدة.
- **الطباعة المباشرة السريعة (Silent Direct Print):** إرسال فوري للطابعة الافتراضية بمقاس A4 بدون نوافذ حوار منبثقة.
